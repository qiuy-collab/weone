微信 AI 陪伴与主动触达桥接器

把微信 Bot、模型运行时、记忆、素材库和主动提醒接到一起，做一个真正能聊天、能记住你、能主动找你说话的 AI 助手。

查看仓库 查看 README

本项目灵感来自 fastclaw-ai/weclaw。

Quick Start

安装
go install github.com/qiuy-collab/weone@latest
源码运行
git clone https://github.com/qiuy-collab/weone.git
cd weone
go build ./...
weone start
  • 默认控制台地址：http://127.0.0.1:18011
  • 先填写 Base URL、API Key、Model Name，再测试连接并保存。
  • 随后绑定微信、设置人设、导入素材、测试普通聊天与主动提醒。

Web 控制台

模型配置、人设设置。
微信绑定、新账号接入、二维码状态查看。
长期画像文档与最近几轮短期会话记忆。
支持文本、图片、视频、文件素材导入、检索、预览与发送。
定时问候、沉默唤醒、事件提醒三类主动任务。

说明

  • 这个 Pages 站点是项目展示页，不是在线控制台。
  • 真正的控制台页面来自本地服务里的 api/static/index.html，并依赖 /api/* 后端接口。
  • 因此 GitHub Pages 适合做项目介绍、截图展示和入口跳转，不适合直接承载运行中的管理面板。
